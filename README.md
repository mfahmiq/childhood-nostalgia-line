# A Childhood Memory

The one sentence that brings back a childhood evening:

> When Grandma lifted the lid, the rice steamed into the kitchen's woodsmoke air while the radio murmured and the summer evening turned gold outside the window, and I never once thought to thank her while she was still there to hear it.

234 characters. One sentence. A grandmother's kitchen, a summer evening, the smell of fresh rice — the three images the judge's brief names — held in a single breath, and an ending that aches: the scene is warm and present-tense until the last clause quietly admits she is gone, and the thanks were never said while she could still hear them.

## How to run

```sh
python3 main.py
```

This prints the memory verbatim to stdout, and writes it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
